# Chapter Notes Template Enhancements

## What's Been Enhanced

Based on Coppermind's structure, we've improved the chapter notes template to capture more useful information:

### 1. **Part Number** ✅
- Added to Metadata section
- Helps readers understand book structure
- Example: "Part 1: Burdens"

### 2. **Chapter Epigraphs** ✅
- New section to capture quotes/inscriptions at chapter start
- These often contain important world-building hints
- Example: "First, you must get a spren to approach..."

### 3. **Enhanced Character Listing** ✅
Now organized into three subsections:

**POV Character(s)**
- Clearly marked point-of-view characters

**Characters Who Appear**
- Characters who actually appear in the chapter

**Characters Mentioned Only**
- Characters who are only mentioned/referenced
- **Why this matters:** Helps answer "Who is X?" questions even when X doesn't appear
- Example: "Tien (mentioned only)" - readers might ask about Tien even if he's just referenced

### 4. **Complete Character Coverage**
- Now includes ALL characters from Coppermind's list
- Even minor mentions are included
- Better for answering character questions

## What Coppermind Provides That We Now Capture

| Coppermind Element | How We Use It |
|-------------------|---------------|
| **Part number** | Added to Metadata |
| **Chapter title** | Already in header |
| **Chapter epigraph** | New "Chapter Epigraph" section |
| **Characters list** | Enhanced with POV/Appears/Mentioned subsections |
| **Plot Summary** | Expanded into detailed Key Beats |

## Benefits

1. **Better Character Questions**
   - "Who is Tien?" can be answered even if he's only mentioned
   - Complete character list helps Rowan identify all references

2. **Part Structure**
   - Readers can understand book organization
   - Helps with "What part am I in?" questions

3. **Epigraphs**
   - Often contain important world-building
   - Help answer questions about magic systems, history, etc.

4. **More Complete Notes**
   - Nothing from Coppermind is lost
   - All information is preserved and expanded

## Example Enhanced Structure

```markdown
## Metadata
- **Part:** Part 1: Burdens
- **POV Character(s):** Lirin

## Chapter Epigraph
> "First, you must get a spren to approach..."
> — [Source]

## Characters in This Chapter

### POV Character(s)
- **Lirin** (POV) — Surgeon in Hearthstone

### Characters Who Appear
- **Hesina** — Lirin's wife
- **Noril** — Traumatized Alethi refugee

### Characters Mentioned Only
- **Tien** (mentioned) — Kaladin's brother, referenced in context of...
- **Dalinar Kholin** (mentioned) — Referenced as...
```
